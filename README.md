# Коробка KV 2027 — 3D

Интерактивный макет коробки 330×210×65 мм с откидной крышкой: карманы без паттерна снаружи, однотонный карман внутри.

Внутри два варианта паттерна — крупный и мелкий, они переключаются кнопками. Другие кнопки открывают коробку и переключают вид сверху. Коробку можно вращать мышью или касанием.

## Локальный запуск

```sh
python3 -m http.server 8765
```

Открыть http://localhost:8765/. Просмотр начинается с закрытой коробки.

Статическая страница использует Three.js 0.165.0 из CDN unpkg.
