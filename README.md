# Коробка KV 2027 — 3D

Интерактивный макет коробки 330×210×65 мм с откидной крышкой и тремя вариантами оформления.

- Вариант 1: карман на внешней крышке и поздравление внутри.
- Вариант 2: карманы с паттерном снаружи, карман с вязаным паттерном внутри.
- Вариант 3: карманы без паттерна снаружи, однотонный карман внутри.

Кнопки позволяют переключать варианты, открывать коробку и смотреть сверху. Коробку можно вращать мышью или касанием.

## Локальный запуск

```sh
python3 -m http.server 8765
```

Открыть http://localhost:8765/. Просмотр всегда начинается с первого варианта и закрытой коробки. Другие варианты и открытие крышки доступны через кнопки.

Статическая страница использует Three.js 0.165.0 из CDN unpkg.
