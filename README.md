# Коробка KV 2027 — 3D

3D-макет открытой коробки 330×210×65 мм с ложементом, устройством и открытками A6.

Открытки показаны крупно: лицо слева, оборот справа. Внизу можно выбрать макет и положить открытку в коробку слева от устройства. У двух вариантов с нотами есть переключатели цвета фона: розовый кружок слева, оранжевый справа. «Полный KV» и «Сокращённый KV» доступны только в тёмном варианте.

Открыть модель: https://rutubaga.github.io/kv-2027-box-3d/box-insert.html

## Локальный запуск

```sh
python3 -m http.server 8765
```

Открыть http://localhost:8765/ или http://localhost:8765/box-insert.html.

Основная модель использует локальную копию Three.js 0.165.0. Текстуры вариантов открыток загружаются по мере выбора, неподвижная сцена перерисовывается только при изменениях.

## Наклейки на устройство

Страница `stickers.html` — 3D-макет проигрывателя-магнита с наклейками: фасад и лента на стенки. Четыре варианта переключаются кнопками: две надписи на боковой стенке, фасад «трек» и вариант в цвете коробки, где градиент переходит с фасада на стенки без шва.

Открыть: https://rutubaga.github.io/kv-2027-box-3d/stickers.html
